# Repository-local skills

Start with [AGENTS.md](../AGENTS.md). These plain-Markdown skills are available to any agent:
read the relevant `SKILL.md` directly if the client does not discover `.agents/skills`.
No plugin, proprietary memory system or automatic client import is required.

| Skill | Use when |
|---|---|
| [markdown-improver](skills/markdown-improver/SKILL.md) | Improving Markdown, instruction clarity, stale links or duplicated guidance |
| [folder-instructions](skills/folder-instructions/SKILL.md) | Adding/updating local AGENTS context or a folder boundary |
| [execute-plan](skills/execute-plan/SKILL.md) | Implementing or closing an existing repository plan |
| [package-validation](skills/package-validation/SKILL.md) | Checking distribution, dependencies or an installed-package regression |
| [unity-editor-workflow](skills/unity-editor-workflow/SKILL.md) | Working with live Unity, imports, metadata, tests or serialized assets |

The catalog describes triggers, not standing work to perform. A documentation edit does not
activate Unity tests, a package audit, a release or every listed skill. Governing instructions
and the user's scope take precedence over optional procedures.
