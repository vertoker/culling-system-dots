# AGENTS.md - `.agents/skills`

Read [the .agents guide](../AGENTS.md) first. The [catalog](../README.md) registers the available
skills and their activation conditions.

Each child skill is self-contained plain Markdown with standard `name` and `description`
frontmatter. Keep trigger descriptions narrow and links relative to the skill file. Do not
add client-only metadata or mandatory sibling-skill chains without a concrete need.
