# AGENTS.md - `Runtime/Dynamic/Ecs`

Read [the Dynamic guide](../AGENTS.md) first. This separate assembly joins the independent
registry to Entities and stock graphics. Capture full Entity identities after transforms,
including objects whose graphics are currently hidden. Never disable simulation entities.

Graphics claims are exclusive with the legacy adapter. Restore stock presentation before
releasing a claim. An invalid capture withdraws old occluders immediately. Only the presentation
owner may transfer graphics after its current GPU resources are ready; CPU preparation is insufficient.
